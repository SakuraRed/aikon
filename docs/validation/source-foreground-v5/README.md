# 已知背景的来源轮廓代理 v5

旧比较仅逐像素按与背景 `#0f0f0f` 的通道距离分类。Cetus真实源的6个深眼缘像素接近背景色，因此在主体内部形成假孔；它们的邻域边界被拿来与SVG外轮廓比较，造成约459.58px的虚假最大距离。这不是绘制轮廓移动了数百像素。

新方法仅输入固定source：保留alpha≥128；与已知背景相差不超过8的像素及alpha不足的像素作为可通行背景，只取从画布边缘8连通可达的部分。封闭在脸内的深色眼缘仍属于主体，实际透明孔仍由alpha排除。未修改source、候选、RGB值、画布、阈值、对齐方式或排除区域。与背景同色且连通的真实前景依然不可恢复；这不是通用抠图，也不用于管理员等未建立背景合同的主体。

实现：[source_foreground.py](../../../tools/source_foreground.py)；7项独立控制覆盖封闭黑眼、外部连通凹口、真实透明孔、透明RGB、裁边前景、同色歧义与非法输入。全部通过。新方法不会决定用户的99%标准。
