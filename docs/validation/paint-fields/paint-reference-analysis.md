## 源规则与示例究竟支持什么

短版韩文 `큰 덩어리의 머리카락, 파스텔 플랫 채색, 최소 음영과 디테일` 对应大块头发、粉彩平涂及最少阴影和细节。完整版 `기본색에 한 단계 정도의 넓고 약한 음영` 指底色上约一档宽阔、较弱的阴影；`큰 색면 한두 개` 限定必要头发高光为一两个大色块。眼睛章节才明确排除 gradient，不能把这条自动推广成全图一律禁止渐变。

这些语义要求控制空间尺度和层次复杂度，不是要求整张图每个像素只有常数色，也不是允许把同一材料拆成大量不同颜色的小面。实际示例含低频色调变化、边界抗锯齿，部分还可见细微纹理；直接把其 raster 的每个亮暗变化追踪成矢量会把非目标细节一并保留。

| 图像 | 实际可见的有效机制 | 不应盲目复制的部分 |
| --- | --- | --- |
| r1 | 蓝色主要发束面连续，沿大尺度方向缓慢变亮；深蓝后发与前发用区域及遮挡区分；白色褶边的暗面依附折叠关系 | 黑底、水印；不能把局部抗锯齿或像素波动拟合成纹理；其宽眼比例是另一个 geometry 维度 |
| short-pink | 大片粉色主面；有限暗粉色片顺发流收尖；刘海下的暖阴影贴近发际遮挡 | 细微 raster 色差；不按“每条弧都要补一个亮面”扩大装饰 |
| short-black | 黑发主体靠少数连续暗面及外侧宽色带区分；刘海切分主要由轮廓和间隙形成 | 外侧较亮边带须结合本图发面理解，不能把整圈所有材料套上 rim light |
| short-blue | 浅蓝连续主面，暗面依附发束边界；部分渐变缓和大面，无独立星形亮片 | 浅色不意味着发丝应增加白色微亮点；不强制把每束做成对称渐变 |
| full-teal | 高光与头顶大弧形受光面相关；深青区域表示发束分离和后层 | 可见主亮带之外还有小椭圆亮斑，且衣领/下巴比当前近景目标更完整；示例不是正文“1–2 大高光”逐项严格实现 |

正确的统一目标是：连续材料面、清楚的发流及前后层次、少量形体有据的色差。不能在看到复杂坏高光后走到“完全不准高光、不准渐变”的相反极端。

## 新附件的缺陷定位与因果修正

以下位置按用户圈注图的相对方位描述，避免将裁切后的像素坐标误套到全图。圈注中的红线不是颜色分析样本。

| 区域 | 可见问题 | 可以成立的机制解释与证据边界 | 修正目标 |
| --- | --- | --- | --- |
| 左上圈 | 明亮三角/多边形在软发面内突兀截断 | 亮暗边界没有同时说明新发束边缘或合理转面；其具体生成算法未知 | 移除孤立亮片，或合并到沿发流的单个宽受光面；不得仅磨圆原亮片就认为根因解决 |
| 中部大圈 | 相接的多段亮面形成星状、凹折、尖楔，亮暗片互相拼接 | 多个局部高光/阴影片可能将连续发束割裂为假切面；不等于已证明使用了自动量化 | 用一个连续底色面恢复发束，必要阴影依附真实遮挡，控制高光整体预算 |
| 右上、右中与下方圈 | 暗发束内部有不规则、低对比度斑驳和多方向色调起伏 | 与单一平滑色场不符；位图纹理、叠色、截图处理均是候选来源，不能凭 PNG 单独判断其软件根因 | SVG 从确定性底色/梯度重建，不采样这些起伏；在远离边缘的区域检查残差 |
| 全图其他黑发区域 | 类似尖楔和近似色叠片重复出现，部分对发束分组没有额外贡献 | 只修圈注会遗漏同类模式 | 对每个主发束做 owner/anchor 审查，并统一检查 P01–P04 |
| 珊瑚粉侧束与青色环 | 多级窄片和强亮暗切换增加了插画式闪亮感 | 环上的部分平面转折可有材质依据，不能将所有硬边都判错 | 保留关键轮廓与材料差，压缩到必要的大色面；其复杂程度与头发一起验收 |

“像素根源”在这里应落实为颜色的生成方式：一个发面由一个可复现的解析色场和少量有依据的遮挡面产生，而不是从原 PNG 的噪声/杂色边界中提取路径。对失败位图做全局调色、降噪或多色量化只改变症状，无法证明伪高光与假转面已经消失。低幅起伏是否本来属于获准 gradient，应通过区域内实际残差与方向判断，而非把所有色差等同于噪声。

## 交付给生产端的修正合同

正式语义合同见 [paint-antipatterns.md](../../../skills/aikon/references/paint-antipatterns.md)。关键执行顺序：

1. 保存用户认可方向的 geometry 版本与哈希/差异；列明仍未验收的局部。先不移动眼位、改裁切或改变身份部件。
2. 为主要发束、脸、珊瑚侧束和青环分别声明材料底色；同一材料共用调色板。允许明确的双色材料，不能靠过度归并改掉身份。
3. 按覆盖关系登记 shadow receiver/anchor，删除无 anchor 的面和无形体依据的高光。先得到干净基础版，再仅加入有必要的一组平滑过渡或大高光。
4. short/full 分别保存生效中文 prompt、参考、geometry、paint、实际 SVG 和预览。生产 prompt 增加可验证的归属与排除规则；忠实源译文不改。
5. 实际查看多尺寸渲染及局部对照，记录结构、像素、视觉、用户反馈四种状态。未获用户最终验收仍标候选。

这一方法可由不同语言模型直接输出可编辑 SVG，并用相同合同复查，不要求调用绘图模型。但“工具与模型无强制依赖”不等于任意模型已证明同等绘制质量；跨模型一致性仍需实际运行相同输入并比较。

## CI 与端到端失败样本范围

下面是可执行测试的覆盖要求，不是本文件已运行并通过的结果。阈值须由实际 good/bad 对照确定，不能凭本文表格冒造通过数值。

| 测试对 | 合法控制样本 | 注入失败及预期拦截 |
| --- | --- | --- |
| 纯色内场 | 干净 solid，边缘有正常抗锯齿 | 内部像素/小路径颗粒：构造检查或 eroded region 的残差检测失败 |
| 连续渐变 | 少量 stops、单一宽缓方向、区域内连续变化 | 锯齿 stops、循环明暗、微弱多频云纹：解析字段/像素残差检测失败；合法 gradient 不应被误杀 |
| 阴影归属 | 贴近发束覆盖边界的一档弱阴影 | 未声明 owner、漏到脸或透明区、透明暗片重叠形成第二档：合同/owner mask 或实际颜色检查失败 |
| 高光预算 | 无高光，或一到两个顺形大面 | 每束各一个高光、过多离散小亮片：数量/连通域审查；一个合法登记但造型错误的星形高光必须交视觉评审拒绝 |
| 上色局部修正 | 同一 geometry，只改变 paint | 偷改轮廓、眼位、遮挡顺序：几何快照差异失败，即使全图误差更低也不能通过 |
| 透明边缘 | 正常半透明抗锯齿边界，深浅底均自然 | 白/黑 matte 光晕、裂缝、外侧杂色小岛：多尺寸 alpha/边界检查失败 |
| 双版完整性 | 同主体、同轮次，short/full 均有实际产物与证据 | 仅复制文件改名、漏生成另一版、将 PNG 嵌入 SVG：对应检查失败 |
| 主体纠正 | DeepSeek 采用用户明确指定 r1 的本轮形象线索 | 退回蓝鲸、继续标 r1 为无关身份：输入合同与视觉身份核对失败，结构 CI 无法独立判断 |

像素结果需绑定真实渲染器、版本、输入哈希、尺寸、颜色空间和 mask。内部检测排除抗锯齿及合法形状边界后，还应单独检查那些边界，防止用“排除区域”隐藏缺陷。不同图像的全图 RGB 误差不能证明风格距离：主体色、造型、构图都会改变它。

端到端测试应让绘制 Agent 先读取实际生产 prompt 和指定参考后创作，主线程再检查 SVG、渲染、局部像素与全图观感，独立评审负责尝试找出反模式。一次同宿主测试可证明这一链路运行过，不能证明所有模型兼容。对已知不自然但结构合法的样本，如果系统仍自动标视觉通过，测试流程本身应失败。
