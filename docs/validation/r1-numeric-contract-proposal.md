## 可选门槛

所有条件取 AND，不把颜色、轮廓或小部件加权平均来互相补偿。

| 条件 | A：多指标联合（建议） | B：99%逐像素命中（更严） |
|---|---|---|
| 全主体平均颜色误差 MAE | ≤2.55/255 | 同A |
| 全主体 RMSE（惩罚大错） | ≤8/255 | 同A |
| 每个冻结局部 ROI | MAE≤5.10/255、RMSE≤10/255；分别通过 | 同A |
| 主体轮廓 IoU | ≥0.995 | 同A |
| 1280像素边界偏差 | 对称95分位≤2px，最大≤8px | 同A |
| 逐像素命中 | 报告分布，不加99%覆盖门槛 | 主体及每个ROI均≥99%的像素，RGB三通道最大误差≤5/255 |

A的2.55来自8bit色程的1%容差；若记录 `100×(1−MAE/255)`，必须命名为“归一化平均颜色接近度”，绝不能命名“视觉相似度”或“用户认可率”。B的99%是明确的像素覆盖率，容差5/255，不是“99%像素完全相同”。两档均不承诺人的视觉观感可被单个百分数替代。
