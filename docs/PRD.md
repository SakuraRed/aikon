# PRD — Aikon

## 产品目标

提供一个标准、可迁移的 Agent Skill，使不同 harness 与模型能根据用户的风格参照、主体资料或图片，通过交互生成 Grok bot 风格 SVG 图标，并持续修改和管理版本。

## 用户与场景

- 用户提供人物、角色、IP 或实体描述，必要时补充图片；Agent 使用经过筛选的风格样例建立视觉目标。
- Agent 使用宿主实际提供的原生问题工具，按依赖顺序询问相互独立的视觉决策，并附可理解的建议和代价。
- 用户选择细节后得到 SVG；继续提出局部修改，能追溯各版差异及保留的条件。

## 已明确需求

1. 最终输出类型必须为 SVG，鼓励代码绘制，减少对绘图模型能力和输出格式的依赖。
2. 参考图必须经过视觉筛选并保存在 ref，不能只列文字链接。
3. 互动问题覆盖正交的设计维度；已有选择不反复询问，不以默认值伪造用户回答。
4. 产物采用结构化目录及版本记录，尊重用户指定的存放位置与管理方式。
5. 支持局部精调及有证据的验证、反馈、修正循环。

## 已通过原生问答确定

- 规范优先，默认保留主体原色；实际偏离需显式记录。
- 问清关键偏好后展示 2–3 张 SVG 候选，再精修。
- 面向通用分发，使用独立编写内容与原创或获授权分发参考。
- 无面部实体默认重构成圆脸机器人，保留主体配色和辨识线索。
- 未指定存放方式时，首次先问目录与版本策略，之后沿用；不采用自动建目录作为默认。

对应真实回答见[决策详情](https://github.com/SakuraRed/aikon/issues/4#issuecomment-5871118157)。

## 首次视觉反馈后的明确变更

用户实际查看首批图后要求加强网页式近景，并作以下覆盖：

- 两版源提示词完整翻译成简体中文，关键术语保留 English；不能只做摘要。
- 一次新增参考的绘图请求为一个 round，同时输出精简版与完整版，不再以任意 2–3 个候选替代。
- 默认透明背景 SVG；忽略参考水印及黑底，除非用户特别要求，成品不得含水印。
- 支持概念、名称、立绘、wiki/URL 等输入，先研究、获取参考并解析，再确认意图；其他模态按实际工具提取，不编造已查看内容。
- 用户强模式参考优先用于目标观感，内置参考辅助，主体身份仍从主体证据获取。

真实测试输入位置记录在验证资料中。管理员男女都测、Aria人形和机器人都测、产物保存在 `outputs/fixtures` 的选择继续有效。DeepSeek 早期蓝鲸路线已由下面的明确纠正覆盖。另有千夏名称和未知姓名的立绘输入；此前七分支十四图全部被拒绝，暂停扩量。

## 2026-09-29 反馈覆盖

- DeepSeek 的典型参考明确为 `ref/user-mode/r1.png`，同时绑定本轮主体形象与模式；不再按品牌蓝鲸绘制，不再次投票。该用户指定形象不等于品牌官方角色声明。
- 用户肯定单例诊断图的整体构图，但明确拒绝异常纹理与不自然高光。保留构图方向，分别管理 geometry、paint、最终验收状态。
- 将 cloud mottling、grain、无依据亮片、半透明主体和量化色带列为反模式；保留有依据的低频渐变、遮挡和少量受光面。
- 提示词必须在绘制前实际保存，区分原始忠实译文与当前执行覆盖。通过明确 geometry + paint plan 和标准库编译减少绘图模型参与。
- CI 从结构、真实像素、合法参考和真实缺陷回归分层检查；端到端实际导出、渲染、查看并记录修正。绿灯不等于高光自然或用户接受。

## 非目标与证据边界

当前不建设托管网页服务或绑定付费绘图供应商。不承诺任意模型必定可完成，不以单模型验证宣称所有 harness 兼容。SVG 语法有效、视觉合格和用户认可分别记录。
