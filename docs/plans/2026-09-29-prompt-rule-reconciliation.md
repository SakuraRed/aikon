## 不应继续保留的默认值

DeepSeek排除鲸鱼；所有面具默认上移；统一rotate即仰头；无资料统一眼色；ellipse冒称capsule；女性发卡等同任意X；full等同缩小头像或多画发束；只有单一跨端哈希相等就称画质提高。

## 不应误删的用户要求

透明真实SVG、无水印、角色身份与风格资料分开、每轮两profile、原生提问、版本记录、r1自然色场、单环境画质门禁。回归原作者不意味着无视已经明确的用户覆盖。

## 执行与因果验证的边界

“生成器没有读取prompt文件”本身不证明prompt完全未起作用：Agent可能先读prompt再写代码。现有不足在于重放测试只能证明这份代码稳定，未验证Skill/提示词是否足够驱动另一Agent正确理解角色。

下一阶段保存以下可审查对应关系：原始资料的关键部位 → 实体事实及未知项 → 用户分支决定 → 当次prompt条款 → 实际SVG图层/形状 → 真实渲染局部 → 用户反馈。独立消费测试不得直接给最终答案SVG或从已有SVG改色冒充新生成。
