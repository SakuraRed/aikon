## 共同视觉语言

十张图均可见两个接近黑色的实心长圆胶囊作为完整的眼睛，没有眼白、虹膜、独立瞳孔或闪点；脸部没有口鼻。两眼大体平行，周围保留了宽阔的无装饰面部空间。圆弧连接脸颊与下巴，腮红为淡色椭圆，而非线条或闪光。

头发用平滑、闭合的大色块和少数明暗块表达，通常没有粗黑外轮廓。深灰背景不带景物，脸与头发占据主要画幅。多数样例左眼较高，头发、眼睛及脸部共同构成向画面右侧下倾的姿态；`short-blonde.jpg` 是明确的方向例外。

身份线索主要集中于发色、长短及刘海轮廓，其次是翘发、马尾、卷束、耳饰和衣领。这里没有原始主体参考，因而只能观察“图中有哪些线索”，不能判定它们是否忠实于原角色、是否凭空增加，也不能断言角色身份。

这组图片体现的是接近扁平的视觉风格，而非已经证明的严格纯色几何：原图可见轻微色调变化与纹理，部分发型含多层阴影或碎高光。不能从 PNG/JPG 的外观反推出作者使用了矢量、指定渐变、压缩噪声或某种生成流程。

## 短版与完整版的语义差别及图文偏差

| 维度 | 短版文本 | 完整版文本 | 样例证据与处理建议 |
| --- | --- | --- | --- |
| 脸色与身份 | 奶油色大圆脸；主要保留发色、发型和代表装饰。 | 保留主体肤色或表面基色；从耳、帽、眼镜、胡须或机械部件等选择必要特征；核心形状约三项；不得从风格图移植外观。 | 现有图几乎都为浅色脸和有发人物，无法覆盖深肤色、无发、非人或机械主体。不要把浅脸视为完整版的强制风格。 |
| 眼部几何 | 同大小、平行，长宽比 3:1。 | 约 2.5–3:1；长轴与两眼中心连线垂直；头眼一起旋转；明确禁止横眼、钩脚与内部装饰。 | 样例支持“胶囊眼”语言，但目视不能证明等大、精确垂直或比例达标；`short-teal.jpg` 的眼睛尤其显得粗短。SVG 可直接约束几何，不必把位图的误差复制进去。 |
| 倾斜方向 | 顺时针 15°。 | 顺时针约 15–20°，明确画面左眼高于右眼。 | `short-blonde.jpg` 与两版方向冲突。角度范围是文本目标，本次没有测量任一样例的实际角度，不能声称其达标。 |
| 裁切与衣服 | 左、下裁切；右上留白；不画躯干、手。 | 左、下裁切；下巴触底或出框；必要时仅保留少量颈部、衣领；仍禁止躯干与手。 | 主参考短版的脸更贴近边缘；full 系列都能看到完整下巴及不同程度衣领。`full-teal.png` 衣领面积尤其明显；`full-black.png` 的手是明确违规。 |
| 色块与细节 | 柔和、粉彩、扁平，最少阴影和细节。 | 主体代表色不强制改色；一层左右宽而弱的阴影；必要高光限制为一两块。 | `short-teal.jpg` 的多处亮色碎高光不适合作“最少细节”范本。暗色头发仍可成立，不能把“粉彩”误解为所有头发都必须变浅。 |
| 交付与修改 | 实际生成一张图。 | 生成请求直接给完成图；对象不明时才澄清；后续只改所请求部分；不得声称完成未生成或未查看的结果。 | 这些是来源工作流语义，现有位图不能证明精确修改或版本一致性；也不能覆盖本项目已明确的原生交互、SVG 和版本管理要求。 |

完整版在身份保留、眼睛坐标关系和冲突处理上比短版明确，但其随附图片并未全部执行文字规定。建议分别保存“文字约束”与“实际视觉观察”，不用全体样例投票消解冲突，也不把“完整版样例”自动视为更高质量。

## Code-first SVG 的可观测验收维度

以下是候选验收方法，不是已经实施的测试或最终阈值。文本数值应先纳入明确的设计约束；未决严格度与身份取舍仍需用户决定。

| 维度 | 可检查证据 | 不能替代的视觉判断 |
| --- | --- | --- |
| 真正矢量与结构 | SVG 有正方形 `viewBox`；主体由路径、基础图形或其他可审计矢量元素构成；不以嵌入或外链位图承载成图。 | XML 可解析不能证明符合目标风格。 |
| 胶囊眼 | 两个实心、无内部装饰的胶囊；共享宽高和圆端参数；在未旋转的脸部坐标中长轴平行、中心同高；检查采用的长宽比与约束一致。 | SVG 元素数量不能直接等同于眼睛数量；仍需查看有没有遮挡、重复、奇怪端部或视觉失衡。 |
| 倾斜与相对位置 | 头部相关元素共享明确变换；渲染后画面左眼中心高于右眼；两眼长轴与眼中心连线垂直。 | 不能只看 `rotate` 数值：变换顺序、坐标系和局部反射可改变最终方向。 |
| 裁切与留白 | 在最终画布查看左、下边缘的实际交界；两眼完整可见；右上存在连续背景区域；检查下巴是否满足当前裁切约束。 | “边界框超出画布”不证明脸确实按要求裁切，可能只有头发或装饰出框。 |
| 色块与脸部 | 明确背景、脸、头发、阴影、腮红的语义色值；查看无口鼻、无多余五官、无粗外轮廓，阴影和高光是否保持大块且克制。 | 多个微小路径即使使用少数颜色，也可能产生过密细节；填色数量不是简洁性的充分证据。 |
| 身份保留 | 对照本次主体参考与已记录的核心特征，逐项标明保留、简化或因冲突调整；风格图的发色、饰物不自动进入主体。 | 只有成图或文件名无法证明身份正确；最终可辨认性需实际查看与用户反馈。 |
| 小尺寸可读性 | 建议在预期显示尺寸查看；若尺寸尚未确定，可将 32、48、64 px 作为候选观察档，分别记录两眼、头部剪影和核心身份特征是否仍能辨认。 | 本轮未制作这些尺寸的渲染，不能声称任何样例已通过。暗发并入背景、细耳饰消失、发隙合并、亮碎片抢眼都是待检风险。 |
| 局部修改 | 按眼、脸、前后头发、特征、背景组织可定位元素；对比修改前后源文件及同尺寸渲染，确认指定修改与保留条件。 | ID、分组或文本 diff 只能辅助定位；“只改一处”仍需要渲染对照，不能仅靠元素稳定断言。 |

## 验证限制

本轮完成的是 10 张静态位图的实际观察和两份提示词的语义对照，没有创建 SVG、测量像素几何、抽取精确调色板、做小尺寸可读性实验或跨 harness 测试。总览有助比较，但其中的缩略图不是指定输出尺寸测试。报告不包含用户视觉验收，不证明参考素材的再分发权利，也不证明任何原始角色的身份还原。
