# DeepSeek / r1 身份证据与基准处理

研究日期：2026-09-29。范围为规划阶段的有界资料研究：实际查看用户 r1/r2、既有研究与若干来源图；没有绘图、去水印、覆盖参考、修改 Skill 或 CI。没有向外部服务上传本地参考图；检索只发送关键词和公开 URL。

## 结论

1. 用户指定 r1 是本项目 DeepSeek 精简版的具体目标，并明确要求提取鲸鱼特征。旧研究把该主体概括为蓝发女仆、排除鲸鱼身份，是错误的解释；“不要画成独立品牌鲸鱼 logo”不能推导成“排除鲸系特征”。
2. r1 右侧在蓝色蝴蝶结后方可见深蓝宽鳍状结构，向右下展开，下面有浅色弧形内层；它与前景细长蓝发是分离的层次。该结构不能只写成后发或裙饰。原作者鲸鱼娘资料明确包含头侧鳍，辅助图也显示相近的头侧结构。
3. **未找到 r1 的同图原始发帖或无水印原图。** 找到的完整女仆 Q 版与鲸鱼娘原作者附图均不是 r1；不能当作 r1 无水印源替换它。r1 自身作者、生成方法、许可仍未核实。
4. DeepSeek 品牌鲸鱼、鲸鱼娘角色谱系、r1 这张 Grok bot 风格图是三层不同证据。品牌图只证实品牌视觉使用鲸鱼；角色资料帮助解释形态；本轮构图、简化方式和光泽仍以用户 r1 为准。

## 后续 r1 基准处理的注意点

- 当前 r1 原件和 SHA-256 必须保留；今后若更新工作用参考，原件、来源及处理记录要能回溯。用户建议去水印不等于可以把补绘像素声称为原作者无水印像素。
- 当前右下水印覆盖头发及背景附近；“扣除水印”不能扩大为删除难匹配主体区域。先定义最小固定评估排除区域，清理派生图与评估掩膜各自版本化。
- 若之后找到声称是原图的文件，先比较构图、局部轮廓、配件位置和清晰区域，再核对像素/哈希。格式转换可改变哈希；同一角色不等于同一图。
- 用户目标仍是通过 Skill 的精简版达到 r1 级别的高度相似。不能用新找到的整身 Q 版替换目标，不能把通用“鲸鱼娘规范”覆盖 r1 的具体简化方式，也不能用背景面积抬高相似度。
- r1 角色身份、风格映射与 SVG 产物质量应分开验收：正确保留鳍不证明仰头正确；有渐变不证明光泽自然；矢量可渲染也不证明主体相似。
