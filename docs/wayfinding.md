# Aikon 研究与决策导航

GitHub Issues 为 canonical tracker，地图采用 `wayfinder:map`，研究、访谈和原型分别使用相应类型标签。子任务用 GitHub sub-issues 关联，阻塞使用原生 issue dependencies。

## 目的地

明确可移植 SVG 图标技能的视觉规则、交互行为、产物管理和验收方式，形成可进入 skill-creator 创建与迭代循环的证据及规范。

## 当前范围

用户明确要求先创建仓库、搭建最小文档、研究网页，再开始访谈。该顺序优先于 wayfinder 默认先访谈再建图的次序。此次允许执行仓库初始化、证据收集、文档与可审查原型；最终技能以研究和真实用户选择为依据推进。

## 状态规则

- AFK research 可以并行，主 Agent 核对报告后记录结论并关闭。
- HITL 决策必须有真实人类回答；推荐或概率不能关闭 ticket。
- 暂未能准确表述的问题保留在地图的 Not yet specified。
