# Spec — 技能行为与验收草案

## 已确定输入输出

输入：风格参照、主体文字或图片、用户已选择的设计细节。输出：可修改的真实矢量 SVG 与当前任务所需的版本记录。

## 行为约束

- 先读取实际输入，区分缺失事实与偏好选择。
- 提问使用当前 harness 实际可调用的原生工具，遵守其 schema；不同工具名称应映射到同一交互语义。
- 已有用户选择继续有效；无法取得答案时保留未答状态。
- 局部修改应说明影响范围，并保留用户指定不变的特征。
- 记录实际生成与验证能力；缺少图像查看能力时不能宣称视觉验收通过。

## 首批验收场景

- 只有主体描述、风格参考由技能提供。
- 主体参考图与风格参考图并存，需要分清用途。
- 用户指定输出目录并请求新建版本。
- 已有 SVG 仅要求修改一个局部，其他条件保持。
- 原生问题工具缺失或未返回答案。
- 文件可解析但渲染存在遮挡、裁切或小尺寸不清楚。

具体视觉阈值、比较案例和测试 harness 待研究与用户选择后确定。本文件不是已通过测试的报告。
