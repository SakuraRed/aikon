# Original example scenes

These three fictional subjects were designed for Aikon. Their palettes, silhouettes and identity features are original scene choices; they are not recreations of website characters, source photographs or third-party vector paths. The JSON files contain editable vector geometry and can be distributed with the skill.

Read these alongside [the visual contract](../../references/style.md), [the two profiles](../../references/profiles.md) and [the scene format](../../references/scene-format.md). All use a 512-unit square, one clockwise head rotation, an equal capsule-eye pair, an intentionally cropped large face and transparent upper-right space. Their exact curves and colors are design choices, not measured properties of outside reference images. Both profiles intentionally omit any painted background or watermark.

Use the examples to learn composition, sparse faces, color-block hierarchy and semantic layer organization. Do not copy their skin colors, hairstyles, hardware or fictional identities into a user's subject unless explicitly requested. Identity must come from that subject's references and choices; the example library is not a closed list of supported subjects.

These are editable demonstration drafts. JSON validity or a successful SVG export is not visual acceptance. Inspect the actual export, including the intended small display sizes, before claiming a scene is visually reviewed; user acceptance remains a separate state.
