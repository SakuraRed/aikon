# 每轮双版本：生效提示词合同

本文件是 Aikon 的运行规则。源提示词的完整中文译文分别为 [精简版](prompts/source-short.zh-CN.md) 与 [完整版](prompts/source-full.zh-CN.md)。首次使用对应 profile 时读取完整译文；其来源、译改及 CC BY-NC 4.0 条件随文件保留，不能把译文当作无来源原创文字。

## 当前覆盖：natural-gloss-v2

2026-09-29 用户明确否定两版近似和完全扁平，要求按 r1 保留自然头发、脸部和眼部光泽，full整体参考更新为较完整分束头发、饰件转面及少量领口的图。该反馈覆盖下面源语义中的纯色眼/极少明暗默认；源译文本身保持忠实。当前执行细节见 [自然光泽与双版差异](natural-gloss-v2.md)。

short 应是紧裁切、主发束更简练、配件更概括的柔和头像，仍有必要的低频色场。full 应恢复主要发束、配件连接与材质转面，必要时带少量领口，整体层次在128px也应可辨。两者必须共享主体身份，并在构图、形状分组或可见结构上有实际差异；只换颜色、改文件名或SVG metadata均不满足本轮要求。

## 两层信息

**源语义层**保留两版真实差异：short 的奶油脸、粉彩、约 3:1 胶囊眼、15°；full 的主体原色、约 2.5–3:1 胶囊眼、15–20°、最多约三项核心身份形态与冲突顺序。两版共享同一个已确认主体和参考角色，但分别形成生产指令及参数。

**Aikon 覆盖层**依据用户产品要求生效，优先于源译文中的冲突项：

1. 输出自包含、真实矢量、**透明背景 SVG**；删除背景矩形，不用白底、黑底或内嵌棋盘格代替 alpha。
2. 每个新增参考绘图请求是一个 round，同时生成 `short.svg` 与 `full.svg`。源译文中的“只输出一张”只描述单个 profile 的生成单位，不取消另一版。
3. 先研究输入、分清主体/风格参考，并通过原生工具确认仍未确定的意图。已有明确选择继续有效。
4. 用户提供的强模式参考可细化构图与精细程度；忽略其中的水印和背景，不将其刻画进产物。除非用户特别要求，SVG 中不得包含任何水印、署名标记或来源站点 logo。
5. 加强脸部超近景，减少无意义的下半脸空白；可保留身份必需的发块、帽形或大型饰件，但双眼必须完整。
6. 保留版本和真实验证记录。生成后展示两个真实预览及对应 SVG，不以“只返图”阻止必要的路径、profile 和检查说明。
7. 两个profile执行同一干净上色原则：不复制grain、量化边界、无归属亮片或主体内部的非预期透明度。依据新参考允许平滑渐变与有形体依据的高光，眼内可有细微暗色色场与边缘光泽；不得误读为白色眼点、虹膜或瞳孔。full的区别来自结构与连续明暗一起表达，不能只加阴影数量。

用户之后对某个任务的明确指令可覆盖默认 profile。记录覆盖值、作用于 short/full 哪一版及真实来源；不能静默改变源译文。

## 每版生产指令的组成

按下列顺序保存为可复核的简体中文任务提示词，关键术语保留英文：

```text
Round / Profile：<round-id> / short 或 full
主体（Subject）：<已确认身份、形态、版本、允许的拟人化>
主体证据：<实际读取或查看的来源，关键特征及尚不确定项>
风格参考（Style reference）：<内置参考、用户强模式参考及实际观察>
本 profile 的中文源规则：<读取对应完整译文，保持 profile 特有条件>
Aikon 覆盖：透明 SVG；无水印；更强 close-up；已答决策与明确例外
保留（Preserve）：<身份线索、用户锁定条件>
变化（Change）：<本次创作或修改的范围>
验收：结构检查 + alpha/深浅底查看 + 眼部/裁切/身份 + 双版对应
Paint：material base + 可选低频色场 + shadow receiver/anchor + 不采用的反模式
```

对于 named entity、wiki、概念，先完成研究再填主体证据。不要把猜测的角色外观写成确定事实，也不要仅把名称插入固定头像模板。

## Round 与 revision

两个 profile 对应同一个 round，不得分别挑选不同人物或不同角色形态，除非用户明示。局部反馈默认作用于用户指定的版本；“两版都改”才同时修改两份。新增参考如果改变身份判断，建立新 round 并记录为何，不覆盖旧轮次。

每个 profile 保存自己的 scene/SVG、生产提示词、引用摘要和 checks。两版都需要实际渲染；一版通过不意味着另一版通过。交付时明确它们真正不同之处；若显式覆盖让二者趋同，也要如实说明，不造虚假差异。
