# direct-svg r002：基于 r001 实际渲染的局部修正

base revision：`revisions/r001/`。原 SVG、实际渲染、脚本、scene、检查结果与实际提示词均已先行归档。已亲自查看 root 生成的 `short-render.png`、`full-render.png`。

## 观察与本轮变更

1. r001 的腮红覆盖深灰前发，左侧还跨出脸面。r002 把腮红置于 `face-clip` 内，并将其绘制顺序移到所有前发块之前；头发正常遮挡腮红，脸域以外透明。腮红坐标随眼部调整，轮廓略缩小。
2. r001 眼长分别为画布的 0.211 / 0.215，视觉过大且眼对偏左。参考反馈中的 r1/r2 眼长约 0.165 / 0.188、眼对中点 x 约 0.334 / 0.327，r002 设 short 眼长 92/512=0.180，full 96.25/512=0.188，源比例仍分别为 3:1、2.75:1。两眼局部中心从 `(70,388)/(236,388)` 调整到 `(84,340)/(248,340)`，经各自旋转后眼对中点 x 分别为 0.3275 / 0.3277，y 分别为 0.6779 / 0.6798；这仅是此例与参考的对应关系。
3. r001 可见脸像向下张开的长空楔，右下颌完全落在画布外。r002 收回脸域右下部分，使面颊在画布内向下颌转弯，同时保留左、底裁切。在原偏右分缝与主扫发之间加入一块连续下垂前发，两个不等长收尾进入眼间上方，缩小中央净面；右侧短刘海同步回收，以留出两眼。
4. r001 halo 与头发之间的空隙偏大。r002 保持长轴 43 度、环宽、尖角和内孔，仅将屏幕中心从 `(350,119)` 移至 `(329,135)`；halo 仍先于头发绘制，让局部环身可以被头发遮挡。

## 保留项

珊瑚主束的钩回轮廓与遮挡关系、后侧小束、原 bob 侧发主走向、short/full 配色与细节差别、头部 15/17 度角度保持不变。没有添加其他身份装饰。

## 状态

本轮只做上述局部修正。结构结果不代表视觉合格；r002 等待 root 再渲染检查，未标 accepted，也不声明效果优于 r001。
