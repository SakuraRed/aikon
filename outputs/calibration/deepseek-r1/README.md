## 参考与实验边界

用户补充的Cetus来源已确认同图：[4096无水印来源与当前采样合同](../../../ref/subjects/deepseek/cetus-desktop/README.md)。当前1280校准图所有RGBA都来自上游，哈希 `60c234f594ad81319fa74bb4fa8392f10a125127d46bf1d3b47e618b25813da2`。没有水印排除区、局部warp或生成补绘。原用户r1保持原字节。

geometry-study 与 paint-study 是**源图辅助的语义重建**：有限部件轮廓加解析色场。它用于研究风格和绘制约束；不能当作另一模型独立消费Skill的结果。independent-consumer 则只读Skill、原始参考和通用渲染器，未读取本目录其它答案SVG、几何或色场；其读取记录保留了进程盘点中看到其它任务文件名的情况，不宣称完全无环境信息。

## 实际验证

主线程真实查看了原图、高清源、各次SVG渲染、差值图及深浅底多尺寸图。新参考比较器的11项测试通过，覆盖背景稀释、关键部位位移、水印区域与非法画布变化，不只是重放成功。

| 当前结果 | 源辅助 v004 | 独立Skill消费 v2 |
|---|---:|---:|
| 主体RGB MAE，0–255 | 2.4504 | 7.0100 |
| 主体RGB RMSE，0–255 | 6.0691 | 20.5643 |
| 主体轮廓alpha代理IoU | 0.998450 | 0.989514 |
| 用户要求99% | 未评定 | 未达成／未验收 |

这些是同一新基准上的还原误差，不能换算成用户审美相似度。轮廓代理受来源边缘及孤立像素影响，mean/max边界距离也完整保留。当前可见剩余差异为右前发与主前发的体积、窄折面连接、鳍与白瓣细边光泽，以及左眼局部轮廓。不能由IoU高就忽略这些差异。

v004的实际 [质量报告](revisions/v004/quality/summary.json)：两眼均通过既有capsule检查，256px边缘通过。没有噪点grain报警；整体paint检查仍fail：鳍浅边、两片白瓣mottle报警，以及三条细折缝腐蚀后无足够不透明内区。相同合同作用于真实上游参考也出现鳍mottle和若干合法色场island报警，详见reference-paint-control.json。这说明该合同对部分自然材质尚有误报／适用性限制，不能削平图像迎合它，也没有修改冻结阈值。两片候选白瓣独有报警仍待区分色场误差与邻接边缘影响。

quality旧字段svg_sha256是规范化换行后的文本hash；validation-binding.json另存实际文件byte hash并说明映射。comparison/manifest使用实际文件hash。没有用错误绑定冒称同一字节文件。
