# DeepSeek r1 单例校准记录

当前候选：[revisions/v007/short.svg](revisions/v007/short.svg)，状态 **draft / 未获用户验收**。本目录不是正式short/full新round，也不是通用Skill效果已达标的声明。

## 参考与实验边界

用户补充的Cetus来源已确认同图：[4096无水印来源与当前采样合同](../../../ref/subjects/deepseek/cetus-desktop/README.md)。当前1280校准图所有RGBA都来自上游，哈希 `60c234f594ad81319fa74bb4fa8392f10a125127d46bf1d3b47e618b25813da2`。没有水印排除区、局部warp或生成补绘。原用户r1保持原字节。

geometry-study 与 paint-study 是**源图辅助的语义重建**：有限部件轮廓加解析色场。它用于研究风格和绘制约束；不能当作另一模型独立消费Skill的结果。independent-consumer 则只读Skill、原始参考和通用渲染器，未读取本目录其它答案SVG、几何或色场；其读取记录保留了进程盘点中看到其它任务文件名的情况，不宣称完全无环境信息。

## 实际验证

主线程真实查看了原图、高清源、各次SVG渲染、差值图及深浅底多尺寸图。新参考比较器的11项测试通过，覆盖背景稀释、关键部位位移、水印区域与非法画布变化，不只是重放成功。

| 前阶段结果（同一v4比较口径） | 源辅助 v007 | 第一轮独立Skill消费 v2 |
|---|---:|---:|
| 主体RGB MAE，0–255 | 2.2723 | 7.0100 |
| 主体RGB RMSE，0–255 | 5.6100 | 20.5643 |
| 主体轮廓alpha代理IoU | 0.998450 | 0.989514 |
| 用户要求99% | 未评定 | 未达成／未验收 |

这些是同一新基准上的还原误差，不能换算成用户审美相似度。轮廓代理受来源边缘及孤立像素影响，mean/max边界距离也完整保留。当前可见剩余差异为右前发与主前发的体积、窄折面连接、鳍与白瓣细边光泽，以及左眼局部轮廓。不能由IoU高就忽略这些差异。

v004的实际 [质量报告](revisions/v004/quality/summary.json)：两眼均通过既有capsule检查，256px边缘通过。没有噪点grain报警；整体paint检查仍fail：鳍浅边、两片白瓣mottle报警，以及三条细折缝腐蚀后无足够不透明内区。相同合同作用于真实上游参考也出现鳍mottle和若干合法色场island报警，详见reference-paint-control.json。这说明该合同对部分自然材质尚有误报／适用性限制，不能削平图像迎合它，也没有修改冻结阈值。两片候选白瓣独有报警仍待区分色场误差与邻接边缘影响。

quality旧字段svg_sha256是规范化换行后的文本hash；validation-binding.json另存实际文件byte hash并说明映射。comparison/manifest使用实际文件hash。没有用错误绑定冒称同一字节文件。

## 后续 v006 验证

在同一上游真无水印基准上，v006实际SVG主体MAE为2.2843/255、RMSE为5.6198，较v004的2.4504/6.0691下降。主体轮廓、眼位与脸路径保持；不能由这个下降换算成99%或用户接受。实际查看了全图、局部、差值与深浅底128/48/24px。

新增两片宽低幅径向glaze与底场共同表达连续体积。所有新拟合色场的完整可见域受约束，旧4个字段的范围警示保留；解析浮点预测与实际8bit预乘合成有数级偏差，失败检查及根因在[材料报告](paint-study/natural-fields-v6/REPORT.md)，最终以实际SVG栅格测量。几何初次冻结后发现尖端平滑错误，撤回版本及完整输入都保留，没有追认重写。

[实际owner回归](revisions/v006/owner-regression.json)证明：v005右脸发缝mask与脸零交叠，却因导出路径没有相同clip，真实渲染侵入脸mask200px（109px深入超过2px）。v006仅施加已有蓝色父域clip，深入像素归零，剩1px边缘采样差；总改变569px，整图alpha完全一致，相关脸部色岛报警消失。

v006两眼及256px边缘仍通过，paint仍fail：鳍浅边mottle、主前发island、第五白瓣mottle及两条薄折线证据不足。不能将全部归为误报；特别是source/candidate材料mask错配必须分别查证。支持域审计已证明旧Gaussian会跨材料借色、内容依赖梯度可能隐藏缺陷、二次趋势不支持任意合法radial。新增诊断报告完整核覆盖，缺样点保持未评估，原门禁与阈值未放宽。见[支持域审计](../../../docs/validation/paint-support-v4/README.md)。

当前单Ubuntu CI追加7项支持域正负测试，本地83项图像检测相关测试通过（16.299s），没有新增平台矩阵。Skill通过skill-creator的quick_validate；隔离画质venv无PyYAML，使用已装PyYAML的现有Python完成检查，未安装依赖。技能入口/引用文档已纠正旧平色helper、full取景和面具上移冲突；本轮没有新的独立绘制消费成绩，上一轮独立v2仍未达标。

## 后续 v007 与可移植归档

v007固定既有几何；主线程实际查看完整图、差值和深浅底多尺寸图。眼内1–4px带的MAE左4.824→3.477、右4.602→3.830，鳍整体RMSE9.191→8.943；全部alpha逐像素相等。相同v4比较合同下主体MAE2.2843→2.2723，属于细节改进而非已证实99%。所有5条旧材质报警继续保留；眼形和256px边缘通过。

[主发色岛独立复核](../../../docs/validation/v006-material-review/README.md)将423px报警定位为左贴脸发梢的连续暗残差。实际绘制栈没有混入其它材料；独立的双宽radial也在同一处重现假岛，而注入的真实色岛/噪点/云纹可被检出。原门禁未改，不为消警提亮/涂平。薄发梢低频污染仍未评估，模型改进需独立验证。

另行修正source轮廓代理，把6个封闭深眼缘像素从误判背景还原到主体。[v5比较](revisions/v007/comparison-v5/report.json)与[原v4比较](revisions/v007/comparison/report.json)分开保留；这只修测量模型，不算改图收益。说明与7项独立控制见[来源轮廓代理](../../../docs/validation/source-foreground-v5/README.md)。

Skill新增仅依赖Python标准库的直接SVG静态检查与归档helper。真实v006/v007已存入[便携归档](portable-archive/)，SVG、实际prompt和metadata raw bytes全部哈希一致；单独复制helper到临时目录、以Python `-I`执行也通过。17项归档测试通过，3.9语法检查通过，实际运行仍仅3.13；未测试其他harness。归档结构通过不提升视觉或用户验收状态。

## 独立消费第二轮与材料工具

[第二轮独立试验](independent-consumer-round2/README.md)只提供Skill和raw参考。主线程重新以同一v5口径对照两轮，主体MAE7.0102→6.3540、RMSE20.5646→18.0959；有改善但未达高精度重建，仍存在7px局部边缘门禁失败。它没有使用本轮正在开发的材料helper，不能把变化归为该helper功劳或推广成跨模型结果。

新增通用标准库 `compose_materials.py`：计划绑定实际geometry SVG，显式指定filled target、连续色场、有限glaze和owner；不预设人物坐标/眼比/调色板，不提取参考图。18项测试包含非identity transform下实际RGBA检查、共享clip边界与错误transform负控、失败清理。真实独立候选的脸色场经新计划/编译器往返，1280px RGBA完全一致；这是表示执行验证，不是画质改善。记录在[实际往返](../../validation/material-composer-real-case/README.md)。

本轮还形成[男女管理员条件式prompt包](../../../docs/prompts/endministrator-branches/index.md)，分别列发型、女性多片发卡、mask正常佩戴、无面具眼部证据及各自full颈领来源。两项mask选择仍为null，未代答或开始绘制。未指定精确3D版本时可按已有官方插画登记工作依据，无需额外投票，但不得把插画冒称实机证明。
