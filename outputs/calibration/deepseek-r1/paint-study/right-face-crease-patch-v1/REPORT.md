# 单字段修正：无来源青白亮针

可用补丁为 `patch.json` 的 `field` 对象，替换 `hair-right-face-crease` 即可；绑定来源、几何、原字段和 mask 哈希。v5 原文件未改。

## 已确认原因

v002 使用的第一色标为 `#aee8ff`，但本面所有 807 个真实可见源像素的最大 RGB 只有 `[102,135,200]`。固定2px腐蚀后只剩216像素、y范围787–893，真实尖端 y745–786 全部不在拟合支持内。近水平原渐变对内区覆盖的 t 范围仅为 0.157–0.790，但导出完整形状会绘制到 t≈0.016，第一端点的非物理外推因而直接成为青白亮针。

真实尖端 y745–774 的中位源色为 `[91,118,187]`；原场预测中位为 `[149.5,198.5,233.5]`。没有证据支持该亮针，它并非真实高光或肤色。诊断保存于 `diagnosis.json`。

## 有界修正及代价

仅此面改为沿其实际长轴 y745→914 的五色标线性场：两端用真实端段中位颜色锚定，三个内色标受本面实际源 RGB 范围约束。不增加图层，不改几何，不改变验收阈值。拟合和误差均包含全部807个可见像素。

| 报告范围 | 原场 RGB RMSE | 修正场 RGB RMSE |
| --- | ---: | ---: |
| 全807可见像素 | 19.438 | 7.683 |
| 尖端63像素 | 61.116 | 0.610 |
| 原216像素腐蚀内区 | 3.587 | 6.087 |

原先只看内区会偏好产生无来源亮针的场；这里明确保留内区误差变大的代价，不通过换指标隐瞒它。

已经将 v002 SVG 仅替换该 gradient，保存为 `field-only-test.svg` 并通过现有 resvg 实际渲染。已查看 `patch-local-comparison.png`：青白针消失。原图的暗楔面整体宽度与起点仍存在几何差异，此补丁不声称修复了全部几何或达到99%。`render-delta.json` 记录实际像素变化范围及 alpha 是否保持不变。
