# 局部材质微光 study 结果

建议主 Agent 集成 `trial-correction.json` 的参数，使用 `gloss_paint.apply_gloss(svg_text, plan)` 或把等价片段并入主导出器。该函数仅依赖标准库，不读取来源图、不做拟合。最终待集成结果是 `trial-correction/after.svg`；实际前后对照在同目录 `full-comparison.png`、`eye-left-comparison.png`、`eye-right-comparison.png`、`fin-comparison.png` 和 `frill-white-05-comparison.png`。

## 来源观察与实际修改

已实际查看 1280 清洁来源、4096 原图显示、原分辨率眼部和鳍裁切、v006 实际渲染，以及主试验和修正后的实际渲染。眼部来源有贴合核体的窄暗缘、向内较弱的亮肩及短距离暖白过渡；v006 暗缘较窄、外白缘较均亮。本轮用原眼轮廓内裁切的有限笔画调整过渡，没有添加独立白点、虹膜或新眼形。

鳍浅边的变化主要集中在材料下缘，保留原 broad field，仅添加从原边界中摘出的开放曲线微光。左折片的对角内部折线不加亮边。白褶边只在 `frill-white-05` 暴露外弧增加很弱的局部光，不围成环；其他六片白褶边保留原样。没有改动 blue fin 上侧阴影，因为它属于另一接收面。

## 有界试验

1. `trial-main.json` 与 `trial-main/` 保存首次实际试验。它改善眼、鳍和单片褶边的窄带误差，但主鳍区域整体 RMSE 从 9.191 略升到 9.225，目视下缘峰值偏尖。
2. 唯一修正 `trial-correction.json` 把主鳍 3 px 笔画 opacity 从 0.38 降到 0.24，把 6 px 笔画从 0.10 调为 0.14，缓和窄峰。其他所有参数不变。没有继续搜索或覆盖旧试验。

两次试验的所有既有命名路径 `d` 均保持；仅替换旧眼缘绘制节点。透明 alpha 在 1280 实际渲染中逐像素与 baseline 相同。修正版改变 14,556 个 RGB 像素。没有增加 bitmap、noise、blur、pattern 或像素量化路径。

## 真实渲染测量

MAE 是 sRGB 8-bit 通道平均绝对误差；下表的窄带为既有固定区域内部距边界大于 1、至多 4 像素处。原始结果见 `trial-correction/metrics.json`，不把这些值换算为整体相似度。

| 左眼 | 4.824 | 3.477 | 4.343 | 4.099 |
| 右眼 | 4.602 | 3.830 | 4.511 | 4.241 |

眼外 1–5 像素暖白过渡 MAE：左 2.377→1.752，右 2.366→1.841。主鳍、左折片与白褶边在距边界 6 像素外的色值完全不变。眼核深处的差异仍很小，左眼 MAE 0.806→0.768、右眼 0.696→0.690。

## 剩余不确定性

来源原图的连续软化仍比少数有限笔画更细腻；本方案改善局部材质感，但不把笔画近似称作精确复现。固定曲线与来源边界的局部偏移，尤其眼的最外 1 像素和鳍下缘，仍影响绝对误差。鳍整区域 RMSE 仍为 8.943，包含固定轮廓和未处理上边缘差异，不能全归因于 paint。没有通过额外色圈掩盖这些几何问题。

单片白褶边的改善很小，不能据此把相同圈线推广到全部花瓣。整图仍有本任务范围外的头发、遮挡与结构差异。本研究仅说明同一来源、同一固定几何上的局部 paint 改善；没有独立 Skill 成功、跨模型泛化、99% 复刻或用户验收结论。

## 交付与复现

- `brief.zh-CN.md`：编写试验代码前已保存的约束与观察。
- `gloss_paint.py`：可移植的纯 SVG paint patch 函数。
- `trial-correction.json`：建议集成参数，包含开放曲线与来源依据。
- `trial-*/before.svg`、`after.svg`、对应 PNG：实际 A/B 全图。
- `trial-*/eye-*-before.svg`、`*-after.svg` 等：同一真实 SVG 的独立局部 viewport；没有嵌入裁切位图。
- `trial-*/open-rim-fragments.svg`：可移植的鳍与单片白褶外弧片段；眼部有限笔画由上述函数和 JSON 明确定义。
- `*-native-crop.png`、`*-source-before.png`：来源原分辨率观察证据。
- `source-profiles.json`：首次试验前边界剖面测量，有限区域掩膜用于分析，未进入 SVG。

所有工作进程均通过现有 `tools.run_visual_e2e.run_bounded` 包装，最长 45 秒；渲染一次约 5 秒正常退出。未安装依赖、启动常驻进程、访问网络或改变 Git 状态。初始读取与进程盘点是一次性宿主命令；后续工作命令均有显式硬超时。首次收尾盘点因嵌套 PowerShell 变量转义失败，改用独立脚本后正常完成；没有重跑渲染。收尾进程记录 `process-final.json` 为 `[]`，本任务没有遗留 worker，临时 Python 缓存已回收。
