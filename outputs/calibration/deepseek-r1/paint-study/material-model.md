# r1 的解析上色模型与限制

本目录为同一来源的**校准实验**。来源未修改，参数从 r1 真实可见像素估计，不是独立 Agent 消费 Skill 后的创作结果，不是总体相似度或自然度验收。

## 实际视觉观察与可解释模型

| 材料 / 部位 | r1 的实际表现 | 对应可编辑 SVG 模型 |
| --- | --- | --- |
| 脸 | 中部偏白，向周围渐入奶油／浅粉；不能按一个统一肤色色块处理 | 一个低频径向场，初拟合中心约 (412,911)，半径约 599；3 色标即可表现大方向 |
| 脸在刘海下的遮挡 | 与主体肤色不同的浅粉窄楔面，是真实遮挡边界 | 独立小面上的 2 色标线性场；不把它泛化为整脸轮廓线 |
| 主发束 | 大片连续的上深下浅蓝色；少量发束边界承载真正的遮挡变化 | 每个真实可见发面一个低频线性／径向场；连续软变化不应人为切成尖三角高光 |
| 右侧发尾与后发 | 不同发束和暗折面互相遮挡，亮的前束与暗的后束存在明确边界 | 先纠正分面，随后各自拟合场；不得靠 5 色标勉强吸收错误 mask 的多材料混合 |
| 头侧鳍与浅边 | 深蓝大面与浅灰紫弧边，二者是不同可见结构 | 鳍一个低幅场、浅边一个场；结构边界由几何描述，不用径向亮块模拟 |
| 白褶头饰 | 各个白瓣中存在轻微收色，灰紫折面明确 | 按真实白瓣和折面分别拟合；不把不连通的全部白瓣强制共用一个全局场，也不按量化色带拆分 |
| 蝴蝶结 | 蓝色宽面、下缘深蓝、两处小的折结构；不是随意加亮片 | 左、右、结心、下缘和已有折线分别处理；宽面色场非常低频 |
| 胶囊眼内部 | 暗蓝而非死黑，内区仅约几个 RGB 通道等级的变化 | 低幅 2 色标场；无需白色高光点 |
| 胶囊眼窄缘 | 外侧暖白窄带，随即是内侧暗蓝边，再到略亮但仍很暗的内区 | 真实胶囊偏移轮廓的少量窄层；不扩展成发光眼，也不靠 blur 隐藏边缘 |
| 腮红 | 近乎均匀的淡粉，左右色值略有不同 | 初拟合纯色已足够接近，不能为了“更有光泽”强加径向高光 |

## 实际 API 与拟合范围

`fit_fields.py` 提供：

- `fit_field(rgb, visible_mask, excluded_mask=None, edge_pixels=2)`：每面仅选 solid、2/3/5 色标 linear 或 radial。确定性最多 3000 样点求参数，完整保留内区计算残差。模型误差接近时保留参数更少的候选；没有高频残差场或噪声贴图。
- `evaluate_field(field, xy)`：以原始 1280 × 1280 画布的像素中心坐标评价色场。
- `svg_paint(field, id)`：返回 SVG 定义与 fill；绝对 `userSpaceOnUse` 坐标，自包含色标，无 image、filter、pattern、mesh 或 blur。

渐变未观测的色标只弱约束到同材料均色，避免最小范数求解把未观测端点变成黑色。实际所有残差依然在完整保留像素上计算。内部 RGB 浮点色标用于精确导出百分比 rgb；JSON 同时提供便于阅读的四舍五入十六进制色值，使用后者会引入最多约半个 RGB 等级的额外量化误差。

`api-checks.json` 是独立构造的纯色、线性场、径向场控制，验证拟合和导出接口，没有用本次 r1 分面反复定义自己的成功标准。

## 排除区必须区分

材料拟合使用 geometry manifest 提前定义的 `watermark-uncertainty.png`（范围 `[1084,1193,1252,1255)`，10416 像素）以及每可见面固定 2 像素边缘带。它们只用于估计材料色场和报告本目录的同材料内部误差。边缘带不代表实际产物免于边缘验证。

主线程的**最终图像比较器**另外冻结 `[1086,1198,1246,1252)` 为水印排除范围；最终误差必须按比较器的范围重新计算，不能引用本目录更大的拟合排除区、内部误差或纯背景面积替代最终验收。本目录将所有未排除的难拟合内区保留在统计中。

## 首版失败证据

`material-fit-v1/` 保存第一次 40 面拟合，`high-residual-regions.png` 保存最差九面的来源、掩膜和解析预览。实际查看后，右侧发尾出现不属于来源的色带；脸、腮红和白瓣比较接近，不意味着整图可用。

首次同材料 RGB RMSE（0–255）为：脸 1.49；腮红 0.80 / 0.99；白瓣约 1.49–2.01；主前发面 5.21；右前发面 6.93；后发浅束 18.03；右内折面 14.95。所有 40 面掩膜互不重叠，已排除“把后绘遮挡误算为当前材料残差”的可能；高误差指向实际分面偏差及少量跨材料像素。此轮不能作为最终绘制结果。

首版使用的 geometry manifest 哈希为 `99cfdebd681bc8ed7ffe42185e3a6ad55640498f276f018a2b73c6b00b8d2837`。之后 geometry 线程清理父底层并更新 manifest，报告该次更改不改变 40 个可见面；但首版未保存完整输入快照，故不能把后来 manifest 与首版参数组合后声称原样可回放。首版只保留诊断用途。后续 `run()` 在拟合前将 manifest、所有 masks 和排除区保存到独立的 `geometry-input/`，参数再绑定该快照及每个 mask 的哈希。

## 第二版交接状态

`material-fit-v2/geometry-input/geometry.json` 为实际冻结输入，SHA-256：`76b80d42d0fb597ccfe1c4b57f706dfe402d505fc53f8d9f502e39c222ea8941`。其 39 面的实际掩膜、父底层和水印不确定区都在快照中；相邻 `fields.json` 对 manifest 与每面掩膜分别绑定哈希。

修正真实材料支撑后，蝴蝶结左面 RGB RMSE 从 11.97 降至 1.26，右面从 5.57 降至 1.72，主前发面从 5.21 降至 3.22。没有增加色标数量或删除高残差像素。脸仍为 3 色标径向，腮红近乎纯色，白瓣有轻微独立场。已实际查看 `material-fit-v2/comparison.png`，右发尾的假色带明显减少。

第二版仍非最终稿：右前发面观感偏平，右内折面和后发的 RGB RMSE 仍分别为 9.97 和 10.19，右前发面为 6.98；边缘、眼缘以及父子面的抗锯齿由主线程实际 SVG 合成后另行验证。`analytic-material-preview.png` 是以测量掩膜显示色场的诊断预览，不是经过最终可编辑几何抗锯齿渲染的交付预览。`analytic-materials.svg` 同样只含各可见面，不能替代有连续父底层的主线程合成结果。

复现第二版只需现有依赖，路径由工作目录决定；建议将输出设为新的版本目录：

```text
python fit_fields.py --source ref/user-mode/r1.png --manifest outputs/calibration/deepseek-r1/paint-study/material-fit-v2/geometry-input/geometry.json --output <new-study-directory>
```

独立 Skill 消费验证和最终相似度比较仍未执行。本目录没有“99% 达标”或用户接受声明。

## 白瓣消融与窄缘补充（已冻结）

主线程实际 v001 SVG 渲染显示白瓣仍偏平后，另保存 `material-fit-v2-petals/`：保持第二版几何及其余材料不变，只将 `frill-white*` 的简单模型选择容差从 0.35 收紧为 0.05 RGB 等级。它不是验收阈值调整，也没有放大色差。七白瓣实际内区 RMSE 从约 1.49–2.01 降至 1.14–1.71；两片原先纯色的瓣恢复低幅变化。`white-petal-ablation.png` 已实际查看，变化有依据但仍不能表达沿任意真实轮廓分布的窄微光。

`material-rim-analysis.json` 按真实 mask 到边界的距离统计来源减解析场：鳍浅边 0–1.5px 的中位差约 `[10.82,10.27,9.26]`，1.5–3px 约 `[7.34,7.41,6.84]`，3–5px 接近零；七白瓣 1.5–3px 的绿色通道差约 +1.75 至 +5.58，8px 后多接近零。该结果与真实放大图相符，说明来源有很窄的顺轮廓亮缘；不能用放大整个径向高光替代。有限宽白色 stroke 裁剪到所属面内部可作为代码实验候选，但需要区分外沿与真实折面边界，未实际渲染验证者不得记录为已修好。

`fin-rim-source-zoom.png` 另清楚显示浅边上的真实分面：左瓣更偏灰紫，中央／右侧较浅，上部存在浅折面。把整条浅边拟合成一个径向场会平均掉这些结构。该观察已交 geometry 线程；其第三版几何随后冻结，但本目录**没有运行第三版拟合**。

冻结原因：用户随后提供 r1 的真实来源线索 `cetus-desktop`；主线程优先追溯原始 SVG 或无水印素材，明确要求停止继续优化旧截图。本目录保持 v1、v2 和白瓣消融的真实证据状态，不把来源尚待核验的线索写成已获得原始资产。所有本目录子进程均已退出。

## 眼缘逐像素证据

右眼中部 y=928 的一条横截线：x=582 的肤色为 `[253,246,242]`，x=584 为 `[254,250,246]`，x=585 为 `[255,253,250]`，x=586 为 `[254,254,252]`，x=587 为 `[253,253,252]`；x=588 为抗锯齿过渡 `[107,106,112]`，x=589 是暗沿 `[15,18,43]`，x=592 是暗蓝核 `[32,37,63]`。

因此只有“暗眼加抗锯齿”不足以描述 r1。应明确保留很窄的暖白外缘和内暗沿，但宽度与幅度都很小。`eye-paint-analysis.json` 同时记录了两眼内侧 0–100px 距边界分带统计；5px 内缘排除仅用于分离眼核拟合，不是眼缘质量的豁免。
