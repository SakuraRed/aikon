# 第三轮独立稿的监督修订

该轮以第二轮独立 Skill 消费结果为起点，使用原始参考作后续修订，未读取 master v001–v007 的 SVG、几何或色场。它是独立稿的监督修订，不能记为新的盲测、跨模型试验或用户验收。

主线程实际查看了 clean source、r004/reference-comparison.png，以及前轮完整/局部/小尺寸图。整体仰头投影和身份关系明显接近，但右前发分界、鳍浅边及蝴蝶结材质仍有可见差异。顶部弯钩仅称 curl/ahoge；它的解剖归属未核实。头侧鲸鳍是蝴蝶结后方宽深蓝结构及其浅边，不把二者混称。

r003 去掉 canvas-crop 的 d 属性值后，与其父稿字节完全相同；主体现有材料没有改动。r004 原始路径、ID 属性及 alpha 保持，改变8850像素，bbox [650,343,831,531]；目标局部 MAE 3.0339→2.7422。分界 y370–390 仍有几何误差，部分双侧色差增加；真实的宽发束色面边界不能为消除接缝而一并抹平。

当前 root/short.svg 仍指向 r003；明确的新局部候选是 [r004/short.svg](r004/short.svg)，SHA `20927e18338f1d8fa131d11cf24fa5ff2eb0367ca85e984060dd4eaa1d338e7d`。二者不能混用报告。

r004 双眼 capsule 检查通过；256px边缘检查仍 fail：超过32/255的局部残差连通块为10px，冻结限值3px，位置在左裁边贴脸发梢附近。已查看该局部；它是采样/材料边缘差异警报，不能直接称为随机噪点，也不能忽略。没有放宽阈值。旧master材料mask不能移植给不同几何，故本轮paint域未借用旧mask伪造通过。

用户尚未接受本轮作品。“99%”已由后续真实回答确定需要数值合同，但具体阈值仍待选择；上述MAE、IoU和归一化派生值均未自动成为验收。
