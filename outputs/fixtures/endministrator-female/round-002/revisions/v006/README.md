# 女管理员 · round-002

当前是供用户视觉审计的候选，未接受。官方女性管理员立绘提供身份；r1 提供自然色场与眼部光泽语言；用户新附件提供 full 的完整分束与少量领口构图。没有复用被拒绝的 round-001 几何。

- `short.svg`：超近裁切，简化大束，省略领口。
- `full.svg`：完整冠发和更多 bob 轮廓，左侧双层扫发、中央前束、右侧前束、前后鬓发及窄领口。
- 两版均有深蓝眼部连续色场与头发低频渐变。full 的宽受光与整个所属发束同形，未添加独立星形、三角高光或细碎噪点。
- 交叉银夹为两根斜交细夹；黄边遮眼面罩被抬高并压薄为额饰，完整露眼，这是创作适配。

`build.py` 只使用 Python 标准库，确定性重建两张 SVG。`render.py` 使用仓库已经锁定的 resvg/Pillow 验证环境导出 1024、128、48、24 像素；每份预览的源文件与 PNG 哈希见 `render-report.json`。`review-sheet.png` 是实际预览的排版，不是新的图像生成结果。

实际视觉检查：已查看两版 1024 渲染与实际小尺寸。双眼完整、男女性别轮廓不同；大图可见连续渐变，小尺寸仍能看到银夹和大束关系。24 像素下银夹及额饰细节变弱，需要用户判断它们是否足以代表管理员。额饰属于明显适配形状而非原作遮眼面罩原样保留；full 的自然度与身份仍等待用户审计。

真实反馈修正见 `revisions/README.md`；早期部分文件已覆盖的局限已记录，没有回填伪造的旧实测文件。

独立复核后的最新窄修订：仅调整右刘海尖端与内曲线，使它和完整右眼分开；双眼与整头变换不动。对真实共享边界缝增加极小底层重叠；正常裁切外缘抗锯齿由扩画布证据确认并保留。量测见 `eye-clearance-report.json`、`alpha-seam-report.json`、`viewport-edge-report.json`，这些不是自然度评分。
