## 实际版本差异

- short：紧脸裁切、五个主要前发分组、七片简化褶瓣，无衣领；蓝色渐变较轻，保留完整暗蓝眼光泽。
- full：较完整头发轮廓、卷曲呆毛、六个前发分组、两组额外后发与侧尾、更多层间转面、十一片大小错落褶瓣、极少衣领和蓝结；发色明暗范围更清晰。
- 两版不是同一张 SVG 改色：裁切、绘制路径、衣领、后发与头饰结构均不同。主发束数量是创作结构说明，不是艺术评分。

## 实际视觉修正

作者已实际查看 r1、用户最新 full 构图附件、旧 paint-v6 扁平稿，以及本轮两版 1024 实际渲染与原生 128/48/24 审阅板。

1. 初稿头饰露出一圈厚灰带、白褶瓣近似尖角。修为白色圆褶瓣、大小不一的展开角度和窄灰紫折缝，让发根遮住内圈。
2. 初稿冠顶独立亮色长片偏硬。删除该片，光泽由连续色场表达。
3. 初稿右刘海贴近眼缘。缩短对应发梢并调整眼位置，使两眼完整露出。
4. 初稿中央发梢存在重复尖牙节奏。移除底层重复发梢，主刘海改成两个长短不同的弯曲收束；full 另有一组内侧顺发流分束。
5. 独立检查在 full 左侧 x=60..62、y=632..647 找到19个内部半透明像素。先保存 `revisions/r004/revision.prompt.zh-CN.md`，再以真实侧发材料重叠修复：1024图共改变134像素，范围 `[58,632,66,682]`，原19像素修后均为alpha255；short SVG及四尺寸PNG与r003归档源码重渲染字节一致。局部核查见 `revisions/r004/repair-check.json`；不以此代替独立复查或用户视觉验收。

最终实际目检：能读出蓝发、白褶边、蓝侧蝴蝶结与卷呆毛的身份线索；眼部为暗色低频渐变与细窄边缘明暗，无白色眼点。头发不再是全平色。未在本轮实际查看的尺寸发现云状噪声或孤立亮片。两版在小尺寸仍能辨识双眼与蓝白身份配色。

这是作者视觉判断，不是用户验收或跨模型一致性证明。full 的画面密度仍低于用户附件的装饰型复杂角色；r1 的白褶边形状和发束曲率存在风格化重构，是否达到用户期望需用户审计。
