# 实际消费提示词：full

Round：illustration-paint-consumer-001。Profile：full。操作：revise paint。本文件在生成 paint plan 与调用上色器之前保存。

主体与证据：同 short，是现有 illustration 的深灰 bob、珊瑚粉回卷侧束和青绿色斜环，不改变主体。用户接受整体造型方向而拒绝奇怪纹理与高光。已实际查看完整反馈图、圈注图和 r1；仅吸收 r1 的连续色场和形体层次，本轮不移植它的蓝发、白褶边或蝴蝶结。DeepSeek=r1 为已明确的其他主体绑定，不继续使用鲸鱼假设。

源语义：full 保留主体代表色与身份关系；大而平滑色面，以底色加约一档宽弱阴影区分前后。高光只是必要时最多一两个大面，本例选择零高光。源允许条件完整不意味着额外亮片或更多细碎发丝。当前操作冻结基础 SVG geometry，不把既有眼比例/倾角冒称符合源 full 的数值条件。

Aikon 覆盖：透明、无水印、真实 SVG，与 short 同轮；不调用 imagegen。保持 `semantic-study-v4.svg` 选中形状的几何与画布不变，将其旧 opacity、旧 gradient 与高光叠片替换为新 paint。任何选中路径变化都应使几何锁检查失败。

Paint：灰发、珊瑚粉侧束、青环及肤面各采用不透明底色和一个宽缓单向双色 linear field；使用同一由左上往右下的低幅变化，避免每束各自发亮。纯色暗面必须有 receiver、receiver-boundary 和真实遮挡/回卷原因；不画局部星形高光、不反复亮暗、不描摹光栅杂色。眼睛和腮红为纯色，腮红 clip 到脸部。把正常材料边界、正常抗锯齿与内部杂纹分开验收，不以全图颜色数下结论。

产物：独立写本目录 r001 paint plan，调用当前 stdlib 上色器，再用固定 renderer 实际渲染 1024、128、48、24 px。全部材料由 SVG 真实绘制顺序产生 mask，调用当前 owner 与 paint field API。若失败，最多新建 r002 作一次有依据修正。保留原始失败证据，不调宽阈值；最终查看深浅背景、局部和小尺寸，结构/像素/视觉/用户验收分别报告。
